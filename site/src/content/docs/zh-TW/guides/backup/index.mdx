Cebian 的資料主要存在瀏覽器本地。換裝置、重灌瀏覽器，或者想在折騰配置前留一份保險時，可以先做一次備份。

備份入口在「設定 → 資料」。這裡有兩種方式：下載到本地，或者上傳到 WebDAV。

![截圖](./snapshot.png)

## 本地備份

本地備份會把資料匯出成一個 `.zip` 檔案，由你自己儲存。

具體操作如下：

1. 開啟「設定 → 資料」
2. 在「本地備份」裡點選「建立備份」
3. 選擇備份模式，必要時開啟「加密備份」
4. 確認後，瀏覽器會下載一個 `.zip` 檔案

如果只是臨時留一份保險，直接建立完整備份就行。

## WebDAV 備份

如果你希望多臺裝置之間都能恢復同一份備份，可以配置 WebDAV。

第一次使用時，需要填寫：

- 伺服器地址
- 使用者名稱
- 密碼或應用專用密碼
- 遠端目錄

填好後可以先點「測試連線」。連線正常後儲存，之後就可以點選「備份到 WebDAV」上傳快照。

WebDAV 頁面會列出伺服器上已有的快照。每份快照都可以恢復，也可以刪除。

## 備份模式

建立備份時有兩種模式：

- 完整備份：包括會話及工作區檔案、普通設定、技能與提示詞、記憶和金鑰資訊
- 部分備份：自己選擇要備份的內容

部分備份裡可以選擇：

- 會話記錄
- 一併備份工作區檔案
- 普通設定
- 技能與提示詞
- 記憶
- 金鑰資訊

普通使用的話，建議直接用完整備份；如果只是想遷移 Prompt 或 Skill，再用部分備份。

## 加密備份

如果備份裡包含「金鑰資訊」，強烈建議開啟加密。

金鑰資訊包括 API Key、OAuth token、WebDAV 密碼等。不開啟加密的話，這些內容會跟備份檔案放在一起，不適合分享給別人。

開啟加密後，需要輸入一個口令。恢復時也必須輸入同一個口令。備份名稱、描述、時間和分類摘要仍是明文，不要在這些欄位裡填寫敏感資訊。

不勾選「金鑰資訊」只會排除專門的憑據欄位，不會掃描並清除對話、記憶、檔案或自定義配置文本中手動寫入的秘密；分享前仍需自行檢查。

> 口令不會被 Cebian 儲存。請牢記口令，如果忘記口令，會導致無法恢復備份。

## 從備份恢復

本地備份和 WebDAV 快照都會進入同一個恢復流程。

恢復前，Cebian 會先顯示備份裡包含哪些內容。你可以選擇要恢復的分類，然後選擇恢復方式：

- 合併：保留本地額外條目，按分類補缺或更新；不是一律用備份覆蓋。
- 替換：會話和檔案分類先清空再還原；設定與金鑰按備份中存在的項覆蓋，不會統一清空所有儲存項。

| 分類 | 合併 | 替換 |
| --- | --- | --- |
| 會話記錄 | 按會話 ID 補入；同 ID 僅備份更新時間更晚時覆蓋，相同時間保留本地 | 清空本地全部會話後寫入備份 |
| 工作區、技能與提示詞、記憶檔案 | 按路徑補入；同路徑僅備份修改時間更晚時覆蓋，相同時間或備份缺少時間時保留本地；不覆蓋本地同名目錄 | 清空所恢復分類的目錄內容，再寫入備份檔案 |
| 普通設定 | 一般設定僅本地從未儲存時補入；自定義 Provider、MCP 伺服器按 ID 補缺；頁面動作與搜尋引擎也保留本地同 ID 配置和已有排序 | 覆蓋備份包含的設定項；備份沒有的項保留本地 |
| 金鑰資訊 | Provider 憑據按 Provider 補缺；已有 WebDAV 配置保留；MCP token 僅為空時補入，自定義 Headers 僅本地整組為空時補入 | 覆蓋備份包含的憑據項；MCP token 和自定義 Headers 只應用到本地已有的同 ID 配置 |

工作區不是獨立恢復選項：恢復「會話記錄」且備份包含工作區時，會一起恢復。檔案按各自修改時間比較，不隨某個會話是否被跳過而跳過。

遷移自定義 Provider 或 MCP 時，通常應同時恢復「普通設定」和「金鑰資訊」。只用「替換」恢復普通設定，會清除被覆蓋配置中的 MCP token / 自定義 Headers，需要再恢復金鑰或重新填寫。

不確定時先選「合併」，但它仍可能覆蓋較舊的同 ID 會話或同路徑檔案。恢復前先備份當前資料，恢復期間不要同時聊天或編輯檔案。

## 備份內容

不同分類對應的內容大致如下：

| 分類 | 內容 |
| --- | --- |
| 會話記錄 | 歷史對話、訊息、會話標題等 |
| 工作區檔案 | 已備份會話對應的 `/workspaces/{會話ID}/` 檔案；不包含已刪除會話遺留的孤立工作區 |
| 普通設定 | 主題、聊天外觀、模型選擇、自定義指引、自定義 Provider 與 MCP 的非金鑰配置、記憶開關與整理設定、頁面動作與搜尋引擎配置等 |
| 技能與提示詞 | `~/.cebian/skills/` 和 `~/.cebian/prompts/` 裡的檔案 |
| 記憶 | `~/.cebian/memories/` 中的長期記憶檔案；開關與整理設定屬於「普通設定」 |
| 金鑰資訊 | Provider API Key、OAuth token、MCP token、MCP 與自定義 Provider 的全部自定義 Headers、WebDAV 連線配置與憑據 |

備份不會包含瀏覽器 Cookie 和網站登入態。所以恢復到新裝置後，有些模型訂閱或網站登入可能還需要重新授權。
