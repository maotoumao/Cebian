VFS 是 Cebian 放在瀏覽器裡的虛擬檔案系統。它不是你電腦上的真實目錄，`/workspaces/`、`~/.cebian/skills/` 這些路徑也不會出現在 Finder 或資源管理器裡。

你可以把它理解成 Cebian 自己的一塊本地檔案區：模型生成的檔案、Prompt、Skill、跨對話記憶和會話工作區裡的資料，都會放在這裡。

## 儲存內容

VFS 裡主要有幾類目錄：

- `/workspaces/{sessionId}/`：每個對話自己的工作區。Cebian 在對話裡生成報告、表格、圖片等檔案時，一般會放在這裡。
- `~/.cebian/prompts/`：Slash Prompt 的提示詞檔案。
- `~/.cebian/skills/`：Skill 資料夾，每個 Skill 通常是一整個目錄。
- `~/.cebian/memories/`：跨對話記憶檔案。
- `~`：等同於 `/home/user`，只是一個虛擬的使用者目錄。

普通使用時，你不需要記住這些路徑。只有在檢視 Cebian 生成的檔案、整理 Prompt / Skill，或者排查檔案連結時，才會接觸到它們。

## 執行機制

VFS 存在瀏覽器擴充套件自己的 IndexedDB 裡。也就是說：

- 資料儲存在本機瀏覽器裡，不會因為 Cebian 有 VFS 就上傳到伺服器。
- VFS 檔案工具與真實磁碟隔離，不會因此獲得任意本機檔案的讀寫許可權。主動上傳、允許訪問本地檔案網址或連線外部工具，是另外的資料入口。
- 解除安裝擴充套件、清理瀏覽器擴充套件資料時，裡面的檔案也可能一起被刪掉。

本地儲存不等於內容永不外發：檔案被模型工具讀取後，返回的內容可能進入模型上下文；使用 WebDAV 備份時，選中的檔案會發送到你配置的伺服器。

Cebian 的檔案工具讀寫的就是這套 VFS。比如模型幫你生成一個 Markdown 報告，實際就是在 VFS 裡建立一個 `.md` 檔案，然後在對話裡給你一個可點選連結。

## 開啟方式

最常見的方式，是從對話裡的檔案連結開啟。

當 Cebian 建立或儲存了檔案，它通常會在回覆裡給出類似「檢視檔案」「開啟目錄」的連結。點選後，會開啟一個獨立的 VFS 瀏覽器頁面。

在 VFS 瀏覽器裡，你可以：

- 檢視目錄和檔案
- 預覽文本、程式碼、Markdown、HTML、SVG、圖片、音影片和 PDF
- 複製路徑；文本類檔案還可以複製原始碼內容
- 下載單個檔案
- 下載整個目錄的 zip

如果你只是管理 Prompt 或 Skill，優先使用設定裡的對應頁面；VFS 瀏覽器更適合檢視檔案結果和工作區內容。

## 預覽與下載限制

單個檔案超過 **50 MiB** 時不在瀏覽器內預覽，可直接下載。壓縮包等不支援預覽的二進位制檔案也只提供下載；音影片是否能播放還取決於瀏覽器支援的編碼。

### PDF

PDF 在 VFS 頁面中按頁顯示，滾動時會更新當前頁碼，底部的「− / +」可以縮放。需要密碼的 PDF 無法在這裡預覽。這裡是檔案閱讀檢視，不是聊天附件上傳入口，也不提供 PDF 文本搜尋或 OCR。

## HTML 預覽與原始碼

HTML、Markdown 和 SVG 都可以用右上角的「預覽 / 原始碼」切換渲染結果與原始檔；程式碼檔案直接顯示帶語法高亮的原始碼。首次開啟 HTML 預設進入預覽，同一 VFS 頁面內會按檔案型別記住你的檢視選擇。

### HTML 的安全邊界

- **Chrome / Edge 等 Chromium 瀏覽器**：HTML 在隔離沙箱中執行，可執行內聯指令碼、載入 HTTPS 外部指令碼與資源，併發起允許的網路請求。預覽內容拿不到擴充套件 API 或擴充套件儲存，但沙箱並不意味著離線，也不能阻止 HTML 將自身內容傳送到外部服務。
- **Firefox**：使用不允許指令碼的靜態預覽，依賴 JavaScript 的互動不會執行。靜態預覽也不等於停用所有外部資源載入。

只預覽可信的 HTML，不要在預覽頁輸入金鑰或其他敏感資訊。「原始碼」檢視只顯示文本，不執行其中的 HTML 指令碼；但首次開啟預設預覽，切到原始碼不代表之前沒有執行過指令碼。
