Cebian 是一個常駐瀏覽器側邊欄的 AI Agent。安裝之後，你可以點選瀏覽器上的 Cebian 圖示開啟它：

## 核心特點

- **本地優先**：對話記錄、Prompt、Skill、記憶和工作區檔案儲存在瀏覽器擴充套件的資料區；本地儲存不等於所有處理都在本地完成。
- **連線自己的模型服務**：配置支援的提供商或相容 API 介面；部分提供商支援登入授權。Cebian 本身不要求註冊賬號，模型服務的賬號、額度和費用由提供商決定。
- **可擴充套件**：可以接入 MCP 工具，也可以把常用操作封裝成 Skill。MCP 支援基於 HTTP(S) 的 Streamable HTTP 和 SSE，不支援直接啟動本機 stdio 服務，詳情見 [MCP 章節](/zh-TW/docs/guides/mcp/)。

## 資料會發到哪裡

| 使用場景 | 資料流向 |
| --- | --- |
| 對話與模型輔助功能 | 相應上下文傳送給所用模型服務，包括訊息、附件，以及讀取後進入上下文的網頁、檔案和工具結果 |
| 聯網搜尋、網頁操作、MCP 與 Skill | 按配置和實際呼叫訪問搜尋引擎、網站、MCP 伺服器或指令碼使用的外部服務；相關結果可能再交給模型 |
| 語音輸入 | 優先在裝置上識別；本地不可用時會回退到瀏覽器的語音服務，音訊可能離開裝置 |
| WebDAV 備份 | 主動備份時將所選資料上傳到你配置的 WebDAV 伺服器 |
| HTML 預覽 | Chromium 沙箱可執行指令碼並訪問允許的外部資源；靜態預覽也不保證完全離線 |

不要把「本地優先」理解為「離線執行」或「資料永不外發」。傳送前檢查敏感內容，並只連線可信的模型和工具服務。瀏覽器配置檔案彼此獨立；解除安裝擴充套件或清理擴充套件資料可能丟失本地記錄，重要內容請先[備份](/zh-TW/docs/guides/backup/)。
