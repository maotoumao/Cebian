安裝完成後，點選瀏覽器工具欄裡的 Cebian 圖示開啟側邊欄。第一次使用時，如果還沒配置模型，會看到「請先選擇一個 AI 模型」。

你需要先給 Cebian 接一個 AI 提供商，然後選擇一個模型，就可以開始對話了。

## 配置 AI 提供商

開啟「設定 → AI 提供商」。Cebian 本身不提供模型額度，也不需要註冊 Cebian 賬號。你可以使用自己已有的 API Key 或訂閱。

目前主要有幾種方式：

- 如果你有 GitHub Copilot 或 OpenAI Codex 訂閱，可以在 OAuth 區域點選「登入」
- 如果你有 OpenAI、Anthropic、Google Gemini、DeepSeek、OpenRouter 等 API Key，可以在「通過 API Key」裡填入並儲存
- 如果你使用 Ollama、LM Studio 或自己搭的 OpenAI 相容服務，可以在 OpenAI Compatible 裡新增自定義提供商

普通使用的話，先配置一個自己最常用的提供商就行，MCP 和 Skill 都可以之後再看。

## 選擇模型

配置完成後，回到新對話頁面，在輸入框左下角點選「選擇模型」。

選擇一個模型後，就可以在輸入框裡輸入內容了。如果當前模型支援思考檔，旁邊還會出現「思考」選項；不知道選哪個的話，先保持預設就行。

## 發出第一條訊息

你可以直接問當前頁面相關的問題，比如：

- 總結一下當前頁面
- 把我選中的內容翻譯成中文
- 提取這個頁面裡的關鍵連結
- 看看我打開了哪些標籤頁，幫我整理一下

Cebian 會帶上當前標籤頁的標題、URL、選中文本和標籤頁列表等上下文。如果需要讀取頁面正文，它會再按需呼叫工具去讀。

## 可以先試試示例

配置好模型後，新對話頁會出現幾個示例卡片，比如「總結當前頁面」「翻譯當前頁面」「提取頁面要點」。

點選示例卡片後，它會把對應的內容填到輸入框裡，你可以直接傳送，也可以先改成自己的說法再發送。

## 上下文用量與壓縮

點選輸入框右下角的用量環，可以檢視上下文已用 / 總量及自動壓縮閾值。用量是估算值；模型未提供上下文視窗大小時，不顯示用量環。

壓縮會把較早歷史整理成摘要，後續請求使用「摘要 + 近期訊息」，減少重複傳送的上下文；原始聊天記錄仍可翻閱。摘要可能省略細節，重要內容建議另存為檔案。

### 自動壓縮

在「設定 → 對話」裡，可以調整自動壓縮開關、觸發比例和壓縮模型。自動壓縮預設開啟，閾值為 80%，可調範圍為 50%–95%。Cebian 在傳送新訊息前，以及連續工具呼叫之間檢查用量，超過閾值時嘗試壓縮。壓縮模型預設跟隨對話模型，也可以單獨選擇。

### 立即壓縮

當壓縮較早歷史能明顯降低上下文佔用時，用量小窗會顯示「立即壓縮」。點選即可提前壓縮，不必等到自動壓縮閾值；關閉自動壓縮後也能使用。新對話通常不會顯示這個按鈕，正在回覆或壓縮時按鈕不可用。

### 取消與失敗

- 壓縮期間會顯示「正在壓縮上下文…」，可以點選輸入框旁的停止按鈕取消。取消不會應用本次摘要；如果是自動壓縮，還會停止當前這一輪。
- **手動壓縮失敗**：會提示錯誤，原有歷史和上下文保持不變，可以稍後重試或檢查壓縮模型的提供商配置。
- **自動壓縮摘要失敗**：重試後仍失敗時，會顯示「此前上下文摘要失敗，已丟棄」，把本次無法摘要的較早內容移出後續模型請求，保留近期訊息和已有摘要；原始聊天記錄仍可翻閱。如果剩下的內容也無法再壓縮，Cebian 會暫停並提示新建對話、從較早回覆分叉或換用更大上下文的模型。

壓縮只整理當前會話的上下文，不會把摘要儲存成跨會話的長期記憶。需要跨對話保留偏好或背景時，請使用[記憶](/zh-TW/docs/guides/memory/)。

## 調整對話外觀

在「設定 → 外觀」中調整對話字型和字號，並檢視即時預覽。

## 如果發不出去

- 提示「請先選擇一個 AI 模型」：回到輸入框左下角選擇模型
- 提供商顯示「未驗證」：API Key 已儲存，但連通性測試沒通過，可以先試著傳送一條訊息看看
- 模型無法讀取網頁、搜尋或執行 Skill：這些操作需要模型支援並啟用「工具呼叫」，請檢查提供商中的模型設定
- 當前頁面無法讀取：Chrome 外掛市場、瀏覽器設定頁、部分特殊頁面本來就不允許擴充套件讀取內容，可以換一個普通網頁再試
