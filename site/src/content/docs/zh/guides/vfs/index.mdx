VFS 是 Cebian 放在浏览器里的虚拟文件系统。它不是你电脑上的真实目录，`/workspaces/`、`~/.cebian/skills/` 这些路径也不会出现在 Finder 或资源管理器里。

你可以把它理解成 Cebian 自己的一块本地文件区：模型生成的文件、Prompt、Skill、跨对话记忆和会话工作区里的资料，都会放在这里。

## 存储内容

VFS 里主要有几类目录：

- `/workspaces/{sessionId}/`：每个对话自己的工作区。Cebian 在对话里生成报告、表格、图片等文件时，一般会放在这里。
- `~/.cebian/prompts/`：Slash Prompt 的提示词文件。
- `~/.cebian/skills/`：Skill 文件夹，每个 Skill 通常是一整个目录。
- `~/.cebian/memories/`：跨对话记忆文件。
- `~`：等同于 `/home/user`，只是一个虚拟的用户目录。

普通使用时，你不需要记住这些路径。只有在查看 Cebian 生成的文件、整理 Prompt / Skill，或者排查文件链接时，才会接触到它们。

## 运行机制

VFS 存在浏览器扩展自己的 IndexedDB 里。也就是说：

- 数据保存在本机浏览器里，不会因为 Cebian 有 VFS 就上传到服务器。
- VFS 文件工具与真实磁盘隔离，不会因此获得任意本机文件的读写权限。主动上传、允许访问本地文件网址或连接外部工具，是另外的数据入口。
- 卸载扩展、清理浏览器扩展数据时，里面的文件也可能一起被删掉。

本地存储不等于内容永不外发：文件被模型工具读取后，返回的内容可能进入模型上下文；使用 WebDAV 备份时，选中的文件会发送到你配置的服务器。

Cebian 的文件工具读写的就是这套 VFS。比如模型帮你生成一个 Markdown 报告，实际就是在 VFS 里创建一个 `.md` 文件，然后在对话里给你一个可点击链接。

## 打开方式

最常见的方式，是从对话里的文件链接打开。

当 Cebian 创建或保存了文件，它通常会在回复里给出类似「查看文件」「打开目录」的链接。点击后，会打开一个独立的 VFS 浏览器页面。

在 VFS 浏览器里，你可以：

- 查看目录和文件
- 预览文本、代码、Markdown、HTML、SVG、图片、音视频和 PDF
- 复制路径；文本类文件还可以复制源码内容
- 下载单个文件
- 下载整个目录的 zip

如果你只是管理 Prompt 或 Skill，优先使用设置里的对应页面；VFS 浏览器更适合查看文件结果和工作区内容。

## 预览与下载限制

单个文件超过 **50 MiB** 时不在浏览器内预览，可直接下载。压缩包等不支持预览的二进制文件也只提供下载；音视频是否能播放还取决于浏览器支持的编码。

### PDF

PDF 在 VFS 页面中按页显示，滚动时会更新当前页码，底部的「− / +」可以缩放。需要密码的 PDF 无法在这里预览。这里是文件阅读视图，不是聊天附件上传入口，也不提供 PDF 文本搜索或 OCR。

## HTML 预览与源码

HTML、Markdown 和 SVG 都可以用右上角的「预览 / 源码」切换渲染结果与源文件；代码文件直接显示带语法高亮的源码。首次打开 HTML 默认进入预览，同一 VFS 页面内会按文件类型记住你的视图选择。

### HTML 的安全边界

- **Chrome / Edge 等 Chromium 浏览器**：HTML 在隔离沙箱中运行，可执行内联脚本、加载 HTTPS 外部脚本与资源，并发起允许的网络请求。预览内容拿不到扩展 API 或扩展存储，但沙箱并不意味着离线，也不能阻止 HTML 将自身内容发送到外部服务。
- **Firefox**：使用不允许脚本的静态预览，依赖 JavaScript 的交互不会运行。静态预览也不等于禁用所有外部资源加载。

只预览可信的 HTML，不要在预览页输入密钥或其他敏感信息。「源码」视图只显示文本，不执行其中的 HTML 脚本；但首次打开默认预览，切到源码不代表之前没有执行过脚本。
