当问题需要当前页面以外的资料时，Cebian 会调用 `web_search` 工具：在一个后台标签页里打开搜索引擎，读取结果，再把「标题 + 链接 + 摘要」交给模型。

用哪些引擎、先试哪个、被拦了换谁，都由你在设置里决定。

## 它是怎么工作的

默认按列表顺序尝试已启用的搜索引擎。模型也可以根据「适用场景」指定先尝试某个引擎，其余引擎仍按列表顺序尝试：

1. 把搜索词填进该引擎的地址模板，在后台标签页里打开。
2. 页面加载完成后，在结果页里运行该引擎的「抽取脚本」，得到结构化结果。
3. 拿到结果就停下；如果引擎返回「被拦截」（比如出现验证码）、没有结果或脚本出错，自动换下一个。
4. 没有取得可用结果时，工具会汇总各引擎的情况，包括没有结果、被拦截、执行失败，以及因时间预算耗尽而未尝试的引擎，供模型说明原因并决定下一步。

Cebian 会尽量复用同一个搜索标签页，创建时不会切换你当前正在看的标签页。搜索标签页被关闭、转去其他网站或无法继续使用时会重新创建；扩展后台重新启动后也可能创建新标签页。你可以随时切换过去查看。

## 调整顺序与启停

入口在「设置 → 对话 → 联网搜索」。

- 列表的顺序就是回退顺序，第一个开着的引擎标为「首选」。用每行右侧的「⋯」菜单可以上移、下移。
- 用开关停用某个引擎。比如你所在地区打不开 Google，把它关掉或挪到最后即可。
- 内置了 Bing、Brave、Google、DuckDuckGo 和百度。百度默认标注「中文查询」，模型会在中文问题上优先考虑它。

## 修改内置引擎

点一行进入编辑页，可以改搜索地址、抽取脚本和「适用场景」。名称跟随界面语言，不可改。

修改过搜索地址、抽取脚本或适用场景的内置引擎会标为「已修改」。在「⋯」菜单里选「恢复默认值」可立即还原；在编辑页点「重置」后还需点「保存」。两种操作都保留启停状态和列表顺序。

搜索引擎改版导致结果读不出来时，不必等 Cebian 发新版，自己改一下脚本就好。

## 添加自定义引擎

点「添加引擎」，需要填：

- **名称**：列表里显示的名字，比如 `Kagi`。
- **搜索地址**：用 `{query}` 占位搜索词，比如 `https://kagi.com/search?q={query}`。Cebian 会把搜索词做 URL 编码后填进去。
- **抽取脚本**：在结果页里运行的一段 JavaScript，见下节。
- **适用场景**（可选）：一句话说明什么时候优先用它，会写进工具说明给模型参考。

不熟悉写脚本也没关系：在脚本编辑器上方的输入框里填结果容器的 CSS 选择器（比如 `#results`），点「生成模板」会得到一份能跑的起手脚本。模板会替换编辑器里的现有脚本；生成后仍要按页面结构调整结果条目、标题和摘要的选择器。也可以在对话里让 Cebian 查看目标引擎的结果页并协助编写，再把脚本贴进编辑器。

## 抽取脚本

脚本必须定义一个完整的 `extract` 函数，在搜索结果页里运行：

```js
function extract({ document, query }) {
  const root = document.querySelector('#results');
  if (!root) return { status: 'empty', results: [] };

  const results = [...root.querySelectorAll('.result')].map((el) => {
    const a = el.querySelector('a[href]');
    if (!a) return null;
    return {
      title: a.textContent.trim(),
      url: a.href,
      snippet: el.querySelector('.snippet')?.textContent?.trim() ?? '',
    };
  }).filter(Boolean);

  return { status: 'ok', results };
}
```

返回值的三种 `status`：

- `ok`：结果容器在，`results` 是抽到的条目。可以是空数组，表示引擎确实没有结果。
- `empty`：结果容器还没出现。有些引擎在页面加载完之后才渲染结果，Cebian 会短暂重试几次。
- `blocked`：明确识别到验证码或拦截页。Cebian 不重试，直接换下一个引擎。

每条结果需要 `title` 和 `url`（必须是 http 或 https 地址，相对地址会按当前页面解析），`snippet` 可选。不合规的条目会被丢弃。

有些引擎会把结果链接包成跳转地址（比如 Bing 的 `bing.com/ck/…`），内置脚本里有解包的写法可以参考。

## Q&A

<QA>
	<QAItem q="搜索时出现验证码怎么办？">Cebian 会继续尝试其他引擎，所以搜索标签页可能已经离开验证码页。如果验证码仍显示在该标签页里，可以手动完成验证后重试；经常遇到拦截的话，把该引擎下移或暂时停用。</QAItem>
	<QAItem q="为什么搜索需要打开标签页？">搜索引擎对扩展发起的裸请求多半会拦，也拿不到你的登录态和地区设置，所以 Cebian 在真实标签页里加载结果页并运行抽取脚本，读取渲染后的内容。新标签页以非激活方式创建，不会切换你正在看的标签页。</QAItem>
	<QAItem q="全部停用会怎样？">模型调用搜索时会得到一条明确的错误，提示你到设置里至少开启一个引擎。</QAItem>
	<QAItem q="脚本会不会被网站的安全策略拦住？">可能。检测到内容安全策略（CSP）拦截时，Cebian 会先尝试在隔离环境里执行；若仍被拦住，Chrome 上还会尝试调试器执行路径，Firefox 没有这条路径。所有可用路径都失败时，Cebian 记录原因并尝试下一个引擎。</QAItem>
	<QAItem q="配置会随备份走吗？">会。引擎顺序、启停、你改过的内置引擎和自定义引擎都包含在「设置 → 数据」的备份里。</QAItem>
</QA>
