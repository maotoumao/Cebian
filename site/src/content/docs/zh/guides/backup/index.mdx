Cebian 的数据主要存在浏览器本地。换设备、重装浏览器，或者想在折腾配置前留一份保险时，可以先做一次备份。

备份入口在「设置 → 数据」。这里有两种方式：下载到本地，或者上传到 WebDAV。

![截图](./snapshot.png)

## 本地备份

本地备份会把数据导出成一个 `.zip` 文件，由你自己保存。

具体操作如下：

1. 打开「设置 → 数据」
2. 在「本地备份」里点击「创建备份」
3. 选择备份模式，必要时开启「加密备份」
4. 确认后，浏览器会下载一个 `.zip` 文件

如果只是临时留一份保险，直接创建完整备份就行。

<Image src={BackupDialogShot} alt="创建完整备份与加密选项" loading="lazy" />

## WebDAV 备份

如果你希望多台设备之间都能恢复同一份备份，可以配置 WebDAV。

第一次使用时，需要填写：

- 服务器地址
- 用户名
- 密码或应用专用密码
- 远程目录

填好后可以先点「测试连接」。连接正常后保存，之后就可以点击「备份到 WebDAV」上传快照。

WebDAV 页面会列出服务器上已有的快照。每份快照都可以恢复，也可以删除。

## 备份模式

创建备份时有两种模式：

- 完整备份：包括会话及工作区文件、普通设置、技能与提示词、记忆和密钥信息
- 部分备份：自己选择要备份的内容

部分备份里可以选择：

- 会话记录
- 一并备份工作区文件
- 普通设置
- 技能与提示词
- 记忆
- 密钥信息

普通使用的话，建议直接用完整备份；如果只是想迁移 Prompt 或 Skill，再用部分备份。

## 加密备份

如果备份里包含「密钥信息」，强烈建议开启加密。

密钥信息包括 API Key、OAuth token、WebDAV 密码等。不开启加密的话，这些内容会跟备份文件放在一起，不适合分享给别人。

开启加密后，需要输入一个口令。恢复时也必须输入同一个口令。备份名称、描述、时间和分类摘要仍是明文，不要在这些字段里填写敏感信息。

不勾选「密钥信息」只会排除专门的凭据字段，不会扫描并清除对话、记忆、文件或自定义配置文本中手动写入的秘密；分享前仍需自行检查。

> 口令不会被 Cebian 保存。请牢记口令，如果忘记口令，会导致无法恢复备份。

## 从备份恢复

本地备份和 WebDAV 快照都会进入同一个恢复流程。

恢复前，Cebian 会先显示备份里包含哪些内容。你可以选择要恢复的分类，然后选择恢复方式：

- 合并：保留本地额外条目，按分类补缺或更新；不是一律用备份覆盖。
- 替换：会话和文件分类先清空再还原；设置与密钥按备份中存在的项覆盖，不会统一清空所有存储项。

| 分类 | 合并 | 替换 |
| --- | --- | --- |
| 会话记录 | 按会话 ID 补入；同 ID 仅备份更新时间更晚时覆盖，相同时间保留本地 | 清空本地全部会话后写入备份 |
| 工作区、技能与提示词、记忆文件 | 按路径补入；同路径仅备份修改时间更晚时覆盖，相同时间或备份缺少时间时保留本地；不覆盖本地同名目录 | 清空所恢复分类的目录内容，再写入备份文件 |
| 普通设置 | 一般设置仅本地从未保存时补入；自定义 Provider、MCP 服务器按 ID 补缺；页面动作与搜索引擎也保留本地同 ID 配置和已有排序 | 覆盖备份包含的设置项；备份没有的项保留本地 |
| 密钥信息 | Provider 凭据按 Provider 补缺；已有 WebDAV 配置保留；MCP token 仅为空时补入，自定义 Headers 仅本地整组为空时补入 | 覆盖备份包含的凭据项；MCP token 和自定义 Headers 只应用到本地已有的同 ID 配置 |

工作区不是独立恢复选项：恢复「会话记录」且备份包含工作区时，会一起恢复。文件按各自修改时间比较，不随某个会话是否被跳过而跳过。

迁移自定义 Provider 或 MCP 时，通常应同时恢复「普通设置」和「密钥信息」。只用「替换」恢复普通设置，会清除被覆盖配置中的 MCP token / 自定义 Headers，需要再恢复密钥或重新填写。

不确定时先选「合并」，但它仍可能覆盖较旧的同 ID 会话或同路径文件。恢复前先备份当前数据，恢复期间不要同时聊天或编辑文件。

## 备份内容

不同分类对应的内容大致如下：

| 分类 | 内容 |
| --- | --- |
| 会话记录 | 历史对话、消息、会话标题等 |
| 工作区文件 | 已备份会话对应的 `/workspaces/{会话ID}/` 文件；不包含已删除会话遗留的孤立工作区 |
| 普通设置 | 主题、聊天外观、模型选择、自定义指引、自定义 Provider 与 MCP 的非密钥配置、记忆开关与整理设置、页面动作与搜索引擎配置等 |
| 技能与提示词 | `~/.cebian/skills/` 和 `~/.cebian/prompts/` 里的文件 |
| 记忆 | `~/.cebian/memories/` 中的长期记忆文件；开关与整理设置属于「普通设置」 |
| 密钥信息 | Provider API Key、OAuth token、MCP token、MCP 与自定义 Provider 的全部自定义 Headers、WebDAV 连接配置与凭据 |

备份不会包含浏览器 Cookie 和网站登录态。所以恢复到新设备后，有些模型订阅或网站登录可能还需要重新授权。

## Q&A

<QA>
	<QAItem q="想迁移到新设备，应该怎么备份？">创建完整备份，建议开启加密，然后在新设备上从文件或 WebDAV 恢复。</QAItem>
	<QAItem q="只想保留 Prompt / Skill 呢？">创建部分备份，只勾选「技能与提示词」即可。</QAItem>
	<QAItem q="恢复时怕覆盖本地数据怎么办？">选择「合并」会保留本地额外条目，但仍可能覆盖较旧的会话或文件；请先备份当前数据。</QAItem>
	<QAItem q="替换会清空所有数据吗？">不会。它只清空并重建所选的会话或文件分类；设置与密钥只覆盖备份包含的项，不是整个扩展状态的镜像还原。操作前请先备份当前数据。</QAItem>
	<QAItem q="WebDAV 连不上怎么办？">先检查服务器地址、用户名、密码和远程目录。有些服务需要应用专用密码。</QAItem>
</QA>
