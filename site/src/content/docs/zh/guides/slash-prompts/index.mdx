Slash Prompt 是一组你自己写的提示词模板。平时输入消息时，只要先输入 `/`，就可以从列表里选一个模板挂到这条消息上。

它适合保存那些你经常重复写的要求，比如总结网页、翻译选中内容、整理会议记录、改写文案等。

## 创建 Prompt

入口在「设置 → 提示词」。

![截图](./snapshot.png)

点击左侧的「新建文件」，创建一个以 `.md` 结尾的 Markdown 文件。编辑内容会自动保存，也可以按 Ctrl/Cmd+S 立即保存。一个 Prompt 文件大致长这样：

```md
---
name: summarize-page
description: 总结当前页面
---

请阅读当前页面内容，用简洁的要点总结它。
```

其中：

- `name` 是斜杠菜单里显示的名字
- `description` 是一行说明，方便你之后区分
- frontmatter 下面的正文，就是最终会发给模型的内容

普通使用的话，先写几个短模板就够了。等用顺手了，再慢慢整理成自己的提示词库。

> 斜杠菜单优先显示 frontmatter 里的 `name`；未填写该字段时，使用去掉 `.md` 的文件名。只会扫描 `~/.cebian/prompts/` 下直接存放的 `.md` 文件，不会递归读取子目录。

## 在对话里使用

回到对话输入框，在文字开头输入 `/` 就会打开 Prompt 列表。

你可以继续输入关键词按名称或描述筛选，用上下方向键选中后按回车，或者直接点击某一项。按 Esc 可关闭列表；没有匹配项时，回车会直接发送输入的 `/关键词`，不会自动调用模板。

Cebian 不会把正文粘进输入框，而是在输入框首行左端挂一枚带色的 `/名字` 标记——再长的模板也不会把你正要写的话淹掉。你可以在它右边接着写自己的要求再发送；也可以只挂着标记直接发，此时 Prompt 本身就是这一轮的请求。

标记不是文字：你选不中它的一部分，光标也进不去。把光标移到文字最前面按一下退格，就能整个摘掉。摘掉之后，这条消息就不再携带这个 Prompt。

发送后，对话里的这条消息就是以 `/名字` 开头、后面接你自己打的话，和普通文字一个样式。Prompt 正文不会在气泡里展开——它是 Cebian 实际发给模型的内容。

## 模板变量

Prompt 里可以写一些变量。Cebian 在**选中模板时**取值并替换，不会在发送时重新取值。切换页面、改变选区或更新剪贴板后，请重新选择模板。

| 变量 | 含义 |
| --- | --- |
| `{{selected_text}}` | 当前页面选中的文字 |
| `{{page_url}}` | 当前页面 URL |
| `{{page_title}}` | 当前页面标题 |
| `{{date}}` | 当前日期 |
| `{{ui_language}}` | 浏览器界面语言的英文名称 |
| `{{clipboard}}` | 剪贴板内容 |

选择模板时会尝试读取剪贴板来准备变量，即使模板没有引用它；只有使用 `{{clipboard}}` 的模板才会把该值填入要发送的内容。

比如：

```md
---
name: translate-selection
description: 翻译选中的内容
---

请把下面这段内容翻译成简体中文：

{{selected_text}}
```

如果某个变量取不到内容，会被替换成空字符串；如果变量名写错了，会原样留在文本里。

## 文件位置

Prompt 文件保存在 VFS 里的 `~/.cebian/prompts/`。

你一般不用手动打开这个路径，直接在「设置 → 提示词」里编辑就行。备份时选择「技能与提示词」，这些文件也会一起备份。
