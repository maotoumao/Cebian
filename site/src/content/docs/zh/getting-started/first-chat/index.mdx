安装完成后，点击浏览器工具栏里的 Cebian 图标打开侧边栏。第一次使用时，如果还没配置模型，会看到「请先选择一个 AI 模型」。

你需要先给 Cebian 接一个 AI 提供商，然后选择一个模型，就可以开始对话了。

## 配置 AI 提供商

打开「设置 → AI 提供商」。Cebian 本身不提供模型额度，也不需要注册 Cebian 账号。你可以使用自己已有的 API Key 或订阅。

目前主要有几种方式：

- 如果你有 GitHub Copilot 或 OpenAI Codex 订阅，可以在 OAuth 区域点击「登录」
- 如果你有 OpenAI、Anthropic、Google Gemini、DeepSeek、OpenRouter 等 API Key，可以在「通过 API Key」里填入并保存
- 如果你使用 Ollama、LM Studio 或自己搭的 OpenAI 兼容服务，可以在 OpenAI Compatible 里添加自定义提供商

普通使用的话，先配置一个自己最常用的提供商就行，MCP 和 Skill 都可以之后再看。

## 选择模型

配置完成后，回到新对话页面，在输入框左下角点击「选择模型」。

选择一个模型后，就可以在输入框里输入内容了。如果当前模型支持思考档，旁边还会出现「思考」选项；不知道选哪个的话，先保持默认就行。

## 发出第一条消息

你可以直接问当前页面相关的问题，比如：

- 总结一下当前页面
- 把我选中的内容翻译成中文
- 提取这个页面里的关键链接
- 看看我打开了哪些标签页，帮我整理一下

Cebian 会带上当前标签页的标题、URL、选中文本和标签页列表等上下文。如果需要读取页面正文，它会再按需调用工具去读。

## 可以先试试示例

配置好模型后，新对话页会出现几个示例卡片，比如「总结当前页面」「翻译当前页面」「提取页面要点」。

点击示例卡片后，它会把对应的内容填到输入框里，你可以直接发送，也可以先改成自己的说法再发送。

## 上下文用量与压缩

点击输入框右下角的用量环，可以查看上下文已用 / 总量及自动压缩阈值。用量是估算值；模型未提供上下文窗口大小时，不显示用量环。

压缩会把较早历史整理成摘要，后续请求使用「摘要 + 近期消息」，减少重复发送的上下文；原始聊天记录仍可翻阅。摘要可能省略细节，重要内容建议另存为文件。

### 自动压缩

在「设置 → 对话」里，可以调整自动压缩开关、触发比例和压缩模型。自动压缩默认开启，阈值为 80%，可调范围为 50%–95%。Cebian 在发送新消息前，以及连续工具调用之间检查用量，超过阈值时尝试压缩。压缩模型默认跟随对话模型，也可以单独选择。

### 立即压缩

当压缩较早历史能明显降低上下文占用时，用量小窗会显示「立即压缩」。点击即可提前压缩，不必等到自动压缩阈值；关闭自动压缩后也能使用。新对话通常不会显示这个按钮，正在回复或压缩时按钮不可用。

<Image src={ManualCompactionShot} alt="上下文用量 78% 的演示会话及立即压缩按钮" loading="lazy" />

### 取消与失败

- 压缩期间会显示「正在压缩上下文…」，可以点击输入框旁的停止按钮取消。取消不会应用本次摘要；如果是自动压缩，还会停止当前这一轮。
- **手动压缩失败**：会提示错误，原有历史和上下文保持不变，可以稍后重试或检查压缩模型的提供商配置。
- **自动压缩摘要失败**：重试后仍失败时，会显示「此前上下文摘要失败，已丢弃」，把本次无法摘要的较早内容移出后续模型请求，保留近期消息和已有摘要；原始聊天记录仍可翻阅。如果剩下的内容也无法再压缩，Cebian 会暂停并提示新建对话、从较早回复分叉或换用更大上下文的模型。

压缩只整理当前会话的上下文，不会把摘要保存成跨会话的长期记忆。需要跨对话保留偏好或背景时，请使用[记忆](/zh/docs/guides/memory/)。

## 如果发不出去

- 提示「请先选择一个 AI 模型」：回到输入框左下角选择模型
- 提供商显示「未验证」：API Key 已保存，但连通性测试没通过，可以先试着发送一条消息看看
- 模型无法读取网页、搜索或执行 Skill：这些操作需要模型支持并启用「工具调用」，请检查提供商中的模型设置
- 当前页面无法读取：Chrome 插件市场、浏览器设置页、部分特殊页面本来就不允许扩展读取内容，可以换一个普通网页再试
