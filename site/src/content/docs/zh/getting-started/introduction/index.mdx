Cebian 是一个常驻浏览器侧边栏的 AI Agent。安装之后，你可以点击浏览器上的 Cebian 图标打开它：

![截图](./snapshot.png)

在完成 AI 提供商配置后，就可以开始对话了。

<Callout type="tip">
第一次使用时不需要一上来就配置 MCP 和 Skill。可以先试试总结网页、提取表格等页面感知能力，再逐步加深。
</Callout>

## 核心特点

- **本地优先**：对话记录、Prompt、Skill、记忆和工作区文件保存在浏览器扩展的数据区；本地保存不等于所有处理都在本地完成。
- **连接自己的模型服务**：配置支持的提供商或兼容 API 接口；部分提供商支持登录授权。Cebian 本身不要求注册账号，模型服务的账号、额度和费用由提供商决定。
- **可扩展**：可以接入 MCP 工具，也可以把常用操作封装成 Skill。MCP 支持基于 HTTP(S) 的 Streamable HTTP 和 SSE，不支持直接启动本机 stdio 服务，详情见 [MCP 章节](/zh/docs/guides/mcp/)。

## 数据会发到哪里

| 使用场景 | 数据流向 |
| --- | --- |
| 对话与模型辅助功能 | 相应上下文发送给所用模型服务，包括消息、附件，以及读取后进入上下文的网页、文件和工具结果 |
| 联网搜索、网页操作、MCP 与 Skill | 按配置和实际调用访问搜索引擎、网站、MCP 服务器或脚本使用的外部服务；相关结果可能再交给模型 |
| 语音输入 | 优先在设备上识别；本地不可用时会回退到浏览器的语音服务，音频可能离开设备 |
| WebDAV 备份 | 主动备份时将所选数据上传到你配置的 WebDAV 服务器 |
| HTML 预览 | Chromium 沙箱可运行脚本并访问允许的外部资源；静态预览也不保证完全离线 |

不要把「本地优先」理解为「离线运行」或「数据永不外发」。发送前检查敏感内容，并只连接可信的模型和工具服务。浏览器配置文件彼此独立；卸载扩展或清理扩展数据可能丢失本地记录，重要内容请先[备份](/zh/docs/guides/backup/)。

## 能力示例

- 总结当前网页、长文、文档或 PR。
- 选中任意内容，让模型总结、翻译、改写。
- 抓取页面里的表格、列表、价格，转成 JSON 或 Markdown。
- 录制一遍操作，让 Agent 之后自己重放。
- 阅读 PDF 文档，回答相关问题。
- ……
