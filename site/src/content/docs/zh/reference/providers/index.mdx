Cebian 本身不提供模型额度。你需要在「设置 → AI 提供商」里接入自己已有的订阅或 API Key，然后在对话输入框里选择模型。

下面只是当前内置 Provider 的列表。实际可用模型会随各家服务变化，以设置页里能选到的模型为准。

## OAuth

这类 Provider 不需要手动填写 API Key，按页面提示登录即可。

| Provider | 说明 |
| --- | --- |
| GitHub Copilot | 使用 Copilot 订阅访问模型 |
| OpenAI Codex | 使用 ChatGPT Plus / Pro 订阅 |

## OpenAI Compatible

如果你使用的是 OpenAI 兼容接口，也可以自己添加 Provider。

常见场景包括：

- 本地运行的 Ollama / LM Studio
- 自己部署的 vLLM、LiteLLM 或网关服务
- 公司内部的 OpenAI 兼容接口

添加时填入名称、Base URL、API Key（如需要），再添加或自动获取模型列表即可。

## 自定义模型界面

在自定义提供商的编辑表单中，点模型旁的设置按钮，可以填写上下文窗口、最大输出，并设置思考和多模态能力。能力参数应按实际服务填写，开启开关不会让服务获得它原本不支持的能力。

不支持工具调用的模型，关闭「工具调用」即可用于普通对话；关闭后不能调用浏览器、文件或 MCP 工具。

### 获取与批量选择模型

点击「自动获取」后，在弹窗中搜索、勾选要加入的模型，再确认。

<Image src={ModelPickerShot} alt="远端模型列表的搜索与勾选弹窗，使用 demo 演示模型" loading="lazy" />

点击模型列表旁的「选择」，可以勾选多个模型或全选，再批量删除。删除只修改当前表单草稿，点击「保存」才生效；「取消」会放弃这次编辑。
