Cebian 本身不提供模型额度。你需要在「设置 → AI 提供商」里接入自己已有的订阅或 API Key，然后在对话输入框里选择模型。

下面只是当前内置 Provider 的列表。实际可用模型会随各家服务变化，以设置页里能选到的模型为准。

## OAuth

这类 Provider 不需要手动填写 API Key，按页面提示登录即可。

| Provider | 说明 |
| --- | --- |
| GitHub Copilot | 使用 Copilot 订阅访问模型 |
| OpenAI Codex | 使用 ChatGPT Plus / Pro 订阅 |

## OpenAI Compatible

如果你使用的是 OpenAI 兼容接口，也可以自己添加 Provider。

常见场景包括：

- 本地运行的 Ollama / LM Studio
- 自己部署的 vLLM、LiteLLM 或网关服务
- 公司内部的 OpenAI 兼容接口

在「设置 → AI 提供商」添加自定义 Provider，填写名称、Base URL、API Key（如需要），并至少加入一个模型。这里使用 OpenAI Chat Completions 兼容协议。

### Base URL 怎么填

填 API 的基础地址，不是网页首页，也不是完整的 `/chat/completions` 地址。Cebian 获取模型时会在其后追加 `/models`，不会自动替你补 `/v1`。

| 服务示例 | Base URL 示例 |
| --- | --- |
| Ollama 本机服务 | `http://localhost:11434/v1` |
| LM Studio 本机服务 | `http://localhost:1234/v1` |
| OpenAI 兼容网关 | `https://api.example.com/v1` |

端口和路径以你的服务配置为准；`localhost` 指运行浏览器的设备。服务无需认证时 API Key 可以留空。自定义 Provider 保存时不做连通性测试，「已配置」不代表请求一定成功。

### 自定义 Headers

在「高级设置」里添加所需请求头，例如网关要求的 `api-key`。Headers 会用于自动获取模型和对话请求。若使用自定义 `Authorization` 鉴权，请清空 API Key；同时填写时 API Key 优先，界面会提示冲突。

备份自定义 Provider 时，模型与端点属于「普通设置」，API Key 和全部自定义 Headers 属于「密钥信息」。迁移完整配置时应同时包含两类。

## 自定义模型界面

在自定义提供商的编辑表单中，点模型旁的设置按钮，可以填写上下文窗口、最大输出，并设置思考和多模态能力。能力参数应按实际服务填写，开启开关不会让服务获得它原本不支持的能力。

不支持工具调用的模型，关闭「工具调用」即可用于普通对话；关闭后不能调用浏览器、文件或 MCP 工具。

### 获取与批量选择模型

点击「自动获取」后，在弹窗中搜索、勾选模型，再确认：

- 这次远端列表中的模型以勾选为准；取消勾选的已有模型会从草稿移除。
- 继续选中的已有模型保留思考、多模态、工具调用、上下文窗口和最大输出设置。
- 不在本次远端列表中的已有模型（包括未被服务列出的手动项）原样保留；若手动项也在远端列表中，则同样以勾选为准。
- 取消弹窗不改变模型列表。确认只修改草稿，最后点击「添加」或「保存」才生效。

获取失败或列表不完整时，可以按服务给出的准确模型 ID 手动添加。先检查 Base URL、认证和网络；获取成功也只代表能读取模型目录，不代表每个模型都有调用权限或支持工具。

点击模型列表旁的「选择」，可以勾选多个模型或全选，再批量删除。删除只修改当前表单草稿，点击「保存」才生效；「取消」会放弃这次编辑。
