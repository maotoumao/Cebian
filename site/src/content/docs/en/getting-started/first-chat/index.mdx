Once installed, click the Cebian icon in your browser toolbar to open the sidebar. The first time you use it, if you haven't configured a model yet, you'll see "Please select an AI model first".

You need to connect an AI provider to Cebian, then select a model, and you can start chatting.

## Configure an AI provider

Open "Settings → AI providers". Cebian itself doesn't provide model credits, and you don't need to register a Cebian account. You can use your own existing API Key or subscription.

There are currently a few main approaches:

- If you have a GitHub Copilot or OpenAI Codex subscription, click "Sign in" in the OAuth area
- If you have an API Key for OpenAI, Anthropic, Google Gemini, DeepSeek, OpenRouter, etc., enter and save it under "Via API Key"
- If you use Ollama, LM Studio, or your own OpenAI-compatible service, add a custom provider under OpenAI Compatible

For everyday use, just configure the one provider you use most; you can look at MCP and Skills later.

## Select a model

Once configured, go back to the new conversation page and click "Select model" in the lower-left corner of the input box.

After selecting a model, you can type in the input box. If the current model supports thinking levels, a "Thinking" option will also appear next to it; if you're not sure which to pick, just keep the default.

## Send your first message

You can directly ask questions about the current page, for example:

- Summarize the current page
- Translate the content I selected into Chinese
- Extract the key links on this page
- See which tabs I have open and help me organize them

Cebian will include context such as the current tab's title, URL, selected text, and the tab list. If it needs to read the page body, it will call a tool on demand to read it.

## Try an example first

After configuring a model, the new conversation page will show a few example cards, such as "Summarize the current page", "Translate the current page", and "Extract page highlights".

When you click an example card, it fills the corresponding content into the input box. You can send it directly, or edit it into your own wording first and then send.

## Context usage and compaction

Click the usage ring at the lower-right of the input to see used / total context and the automatic compaction threshold. Usage is an estimate; the ring is hidden if the model does not declare its context window size.

Compaction summarizes earlier history so later requests use the summary plus recent messages, reducing repeated context. The original chat history remains available to browse. Summaries can omit details, so save important content to a file.

### Automatic compaction

Under "Settings → Chat", configure automatic compaction, its trigger percentage, and the compaction model. Automatic compaction is enabled by default at 80%, adjustable from 50% to 95%. Cebian checks usage before sending a new message and between successive tool-calling turns, and attempts compaction above the threshold. The compaction model follows the chat model by default, or you can select a separate one.

### Compact now

Once compacting earlier history would noticeably reduce context usage, the usage popover shows "Compact now". Click it to compact before reaching the automatic threshold, even with automatic compaction turned off. New chats usually do not show this button, and it is disabled while replying or compacting.

<Image src={ManualCompactionShot} alt="Demonstration conversation at 78% context usage with the Compact now button" loading="lazy" />

### Cancellation and failures

- While "Compacting context…" is shown, click the stop button beside the input to cancel. Cancellation does not apply the new summary; cancelling automatic compaction also stops the current turn.
- **Manual compaction fails**: an error is shown and the existing history and context remain unchanged. Retry later or check the compaction model's provider configuration.
- **Automatic summarization fails**: if it still fails after retrying, Cebian marks earlier context as dropped and excludes the portion it could not summarize from later model requests, retaining recent messages and any previous summary. The original chat history remains available to browse. If the remaining content cannot be compacted further, Cebian pauses and suggests starting a new chat, forking from an earlier reply, or choosing a model with a larger context window.

Compaction only manages context within the current conversation; it does not save the summary as cross-conversation memory. Use [Memory](/en/docs/guides/memory/) to retain preferences or background across chats.

## If you can't send

- Prompt "Please select an AI model first": go back to the lower-left corner of the input box and select a model
- Provider shows "Unverified": the API Key is saved, but the connectivity test didn't pass; try sending a message and see what happens
- The model cannot read pages, search, or use Skills: these actions require a model with tool calling enabled; check its model settings under the provider
- The current page can't be read: the Chrome Web Store, browser settings pages, and some special pages simply don't allow extensions to read their content; try a regular web page instead
