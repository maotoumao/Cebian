You can install Cebian in any of the ways below. For everyday use, installing from an extension store is recommended; if you want the latest version right away, you can download it from GitHub Release.

## Browser requirements

- Use a recent desktop Chrome, Edge, or Chromium browser that supports sidebar extensions.
- Firefox requires **140.0 or later**.

Browser capabilities differ:

| Feature | Chrome / Edge and other Chromium browsers | Firefox |
| --- | --- | --- |
| Mobile mode | Available with the debugger API | Not available |
| Network recording | Requests, responses, and limited stream-message contents | Requires `webRequest` permission; request details and response metadata, but no response bodies or stream-message contents |
| VFS HTML preview | Scripts can run inside an isolated sandbox | Static preview without scripts |
| Voice input | Depends on the speech API, language packs, and network | Hidden when no speech-recognition API is available |

Firefox has no debugger fallback: strict page security policies may block some in-page scripts, and Skills cannot use `executeInPage`. Ordinary chat and features that do not depend on these APIs are unaffected by these differences. See [Input tools](/en/docs/guides/input-tools/) and [VFS file system](/en/docs/guides/vfs/) for details.

## Install from an extension store

Firefox, Chrome, Edge, and most Chromium-based browsers can install from their extension stores:

- [Chrome Web Store](https://chromewebstore.google.com/detail/dnfmklmdbipiahdjiogaoemjaiodomdf)
- [Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/kakfgcmbiacmclkjboijakkhlhioopcd)
- [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/cebian-ai-side-panel-agent/)

Open the corresponding page and click the install button. Once installed, the Cebian icon will appear in your browser toolbar; click it to open the sidebar.

> Store versions go through review, so they may update a little later than GitHub Release.

## Install from GitHub Release

Updates are also published to GitHub at the same time. You can download the latest version from Releases:

[Cebian GitHub Releases](https://github.com/maotoumao/Cebian/releases)

### Chrome / Edge / Chromium

The installation steps are:

1. Download `cebian-{version}-chrome.zip`
2. Unzip it into a fixed directory
3. Open your browser's extension management page
4. Enable "Developer mode"
5. Click "Load unpacked"
6. Select the directory you just unzipped

### Firefox

The Release package `cebian-{version}-firefox.zip` is suitable for temporary testing, not Chrome's "Load unpacked" procedure:

1. Download the Firefox zip
2. Open `about:debugging` and select "This Firefox"
3. Click "Load Temporary Add-on" and select the zip, or `manifest.json` from its extracted directory

The temporary installation ends when Firefox restarts. For everyday use, install the signed version from Firefox Add-ons. See [Mozilla's temporary installation guide](https://extensionworkshop.com/documentation/develop/temporary-installation-in-firefox/).

## Choosing an installation method

- Everyday use: the extension store is the easiest
    - Edge users: prefer the Edge Add-ons store
    - Chrome / Chromium users: prefer the Chrome Web Store
    - Firefox users: prefer Firefox Add-ons

- Want the latest version: GitHub Release is usually fastest

## After installation

Once installed, click the Cebian icon in your browser toolbar to open the sidebar. The first time you use it, you need to configure an AI provider, and then you can start chatting.
